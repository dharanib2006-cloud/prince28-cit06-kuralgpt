# KuralGPT – Data Sources

This file records the sources used for Thirukkural content, their formats, and usage terms.

## 1. Thirukkural Dataset – tk120404

- Source: https://github.com/tk120404/thirukkural
- Format: JSON (`thirukkural.json` and `detail.json`)
- Content: 1,330 Thirukkural couplets, Tamil text, English translations, transliterations, commentaries, and chapter structure.
- Usage terms: Repository lists Apache License 2.0. However, this licence may not cover third-party modern commentaries. Use only content whose reuse rights are confirmed, and provide attribution.

## 2. Project Madurai

- Source: https://www.projectmadurai.org/
- Format: HTML and PDF; some older texts may use TSCII encoding, while newer texts may use Unicode UTF-8.
- Content: Tamil literary works, including Thirukkural texts and related classical literature.
- Usage terms: Free access and personal use are provided. Redistribution conditions may vary by text. Preserve the Project Madurai header, logo, and acknowledgements where required. Check the individual text's terms and contact the coordinators before online redistribution.

## Notes

- Record the source and usage terms for every dataset before adding it to KuralGPT.
- Do not assume that modern commentaries or translations are automatically covered by the licence of a repository.
